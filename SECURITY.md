# Security

Please don't report a vulnerability in a public issue.

Report it privately through
[GitHub](https://github.com/MeandrousShark/wineo/security/advisories/new), or
email [security@hannoncloud.com](mailto:security@hannoncloud.com). Include
the wineo version, how to reproduce it, and what it lets someone do.

Fixes land in the latest release, so only that release is supported.
