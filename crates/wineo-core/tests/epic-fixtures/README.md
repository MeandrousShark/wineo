# Legendary output fixtures

Real output of Legendary 0.21.1, captured once against a real Epic account
(plan 0073, step 0) and then rewritten so nothing of that account or its
library is left: game names, ids, paths, addresses, and account values are
all made up. The shapes, keys, and messages are Legendary's own.

- `*.json`: what a command printed on stdout.
- `*.stderr`: what it printed on stderr. Long ones keep their first and last
  lines, with `...` between.

Add a fixture only from scrubbed output. Never paste raw Legendary output
here: it carries account ids and one-use login codes.
